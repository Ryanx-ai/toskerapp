# Functional icon system

Tosker uses `lucide-react` for familiar product controls. Lucide is distributed under the ISC license, with inherited Feather icons covered by MIT; the installed package includes its license text. Static imports keep the icon bundle tree-shakeable.

Functional icons stay neutral, recognisable, and consistently stroked. Tosker identity comes from layout, typography, colour, interaction, and future approved atmosphere artwork—not from redrawing standard controls.

The current `toskerArt/` development library is not production-approved. None of its icons, motifs, backgrounds, banners, or covers are runtime dependencies.
